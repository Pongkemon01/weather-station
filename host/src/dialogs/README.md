# Per-feature dialog classes go here.
# Each dialog is a triple: name.h, name.cpp, name.ui.
#
# When adding a new dialog:
# 1. Create name.ui in Qt Designer.
# 2. Create name.h and name.cpp following the MainWindow pattern.
# 3. Add all three to APP_SOURCES in ../../CMakeLists.txt.
# 4. The CMAKE_AUTOUIC_SEARCH_PATHS in CMakeLists.txt already covers this
#    directory, so ui_name.h will be generated automatically.
